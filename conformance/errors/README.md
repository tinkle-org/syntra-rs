# Error conformance (approved equivalent)

Test-case IDs use the `CONF-ERR-*` prefix. They are **test identifiers, not normative requirement IDs**: normative force stays with the cited `SNTR-*` requirements. Location `conformance/errors/` is the approved equivalent of `conformance/requirements/errors.*` per `specifications/core/conformance.md` (§Trace: `SNTR-ERR-*` → `conformance/errors/`).
