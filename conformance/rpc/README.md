# RPC conformance (approved equivalent)

Test-case IDs use the `CONF-RPC-*` prefix. They are **test identifiers, not normative requirement IDs**: normative force stays with the cited `SNTR-*` requirements. Location `conformance/rpc/` is the approved equivalent of `conformance/requirements/rpc.*` per `specifications/core/conformance.md` (§Trace: `SNTR-RPC-*` → `conformance/rpc/`).

- [RPC tests](rpc.md) — `CONF-RPC-001…013` (basic, concurrency, ordering, IDs, methods, deadlines, cancel, idempotency, exhaustion, loss, concurrency floor).
